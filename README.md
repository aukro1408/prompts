# Промпты

Коллекция собственных промптов для генерации изображений.

- Приветственный экран со слайдером разблокировки
- Добавление / редактирование / удаление промптов (шторка снизу)
- Категории, теги, избранное, поиск, копирование в буфер
- Данные хранятся локально в браузере (`localStorage myprompts.v1`)

Живая версия: https://aukro1408.github.io/prompts/
